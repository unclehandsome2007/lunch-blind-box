## Lunch Blind Box 蛤，又要吃午餐了

## 專案簡介

本專案旨在解決日常生活中常見的「午餐選擇障礙」，結合了「盲盒隨機推薦」、「步行時間計算」與「多人即時聚餐輔助」的概念 。使用者只需透過滑桿設定願意步行的時間，系統便會自動篩選出限時內絕對能抵達的餐廳並進行盲盒抽取 。

專案具備多項進階功能，包含避免重複踩點的足跡評價系統、下雨自動縮短距離的天氣連動防禦機制，以及專為「胖手指」與 PWA (Progressive Web App) 升級的手機優先介面設計 。此外，針對多人聚餐情境，內建了多端連動的房間系統，能一鍵找出朋友間的「交集餐廳」，並自帶群組分帳小幫手 。

---

## 執行方式

1. 確保電腦已安裝 Python 環境。

2. 透過終端機執行指令安裝專案所需的 Python 套件列表 ：
`pip install -r requirements.txt` (套件包含 Flask、requests、folium 與 gunicorn 等) 。

3. 於專案根目錄啟動應用程式的主入口點 ：
`python app.py`

---

## 主要檔案與架構說明

* **`app.py`**
應用程式的主入口點，處理所有路由與邏輯 。負責單人模式的工序整合，並作為多人連線房間系統的中間人，將資料轉交給大腦運算並同步狀態 。


* **`requirements.txt`**
記錄專案所需的 Python 套件列表 。


* **`api/nominatim_api.py`**
用於 Nominatim 地理編碼 API 的請求 。負責將地址字串轉換為座標，並利用同心圓與黑名單機制撈取附近的真實餐廳名單 。


* **`api/osrm_api.py`**
用於 OSRM 路由 API 的請求 。負責計算真實的走路時間與路徑，並內建直線防呆機制以修正圖資繞路的缺陷 。


* **`api/weather_api.py`**
用於天氣 API 的請求 。透過輸入經緯度查詢當地即時天氣，若偵測到降雨則提供訊號讓大腦縮短使用者的步行限時 。


* **`services/map_service.py`**
整合地圖功能的服務邏輯 。利用 folium 套件修正座標顛倒問題，並動態生成標記起終點、導航藍色虛線與原生跳轉按鈕的互動式地圖 。


* **`services/room_service.py`**
處理房間狀態與預訂的服務邏輯 。作為多人連線模式的大腦，負責計算房間內所有人的幾何中心，利用多執行緒找出大家都能在限時內抵達的交集餐廳 。


* **`templates/`**
HTML 模板資料夾 。包含 `demo.html` (展示頁)、`index.html` (抽盲盒系統主程式) 與 `room.html` (多人連線房間網頁) 等前端渲染檔案 。
